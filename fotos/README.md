# Fotos de las cuatro estaciones

Cada foto aparece sola en la ficha de su especie si se llama así (en minúsculas, salvo la letra
del código):

- `A-71-primavera.jpg`
- `A-71-verano.jpg`
- `A-71-otono.jpg` ← «otono», sin tilde
- `A-71-invierno.jpg`

Formato .jpg, con el lado mayor de unos 1200 píxeles. Para subirlas: **Add file** →
**Upload files** → arrastrarlas → **Commit changes**.
